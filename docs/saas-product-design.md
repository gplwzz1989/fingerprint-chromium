# SaaS 商业产品页面设计计划

## 目标与参考

指纹云控的核心用户是需要批量管理账号环境的个人与团队。高频任务是查找账号、打开隔离环境、同步或恢复环境、分配团队权限；页面应围绕这些任务组织，不以展示技术能力或装饰图表为主。

参考 [shadcn 官方工作台布局](https://ui.shadcn.com/blocks?category=dashboard) 的侧栏、表格和表单组件体系，以及 [AdsPower 官方批量环境管理](https://www.adspower.com/multi-profiles-management) 的环境列表与批量工作流。[AdsPower 团队分组](https://help.adspower.com/docs/groups) 用于对照权限的可见性；本项目仍以现有工作区/账号权限模型为准，不直接复刻其他产品的分组或同步语义。

采用 shadcn 风格：中性色背景、细边框、克制阴影、统一圆角与密集表格，用绿色表示成功、橙色表示待处理、红色表示失败。品牌保持“指纹云控”。组件与信息层级参考商业产品，业务必须接入真实接口。当前独立 HTML/CSS/JS 项目先采用对应视觉规范，不因视觉建议立即安装 React 或新增依赖。

## 页面与交互

| 页面 | 主要工作流 | 必须覆盖的状态 | 进度 |
| --- | --- | --- | --- |
| 账号工作台 | 工作区选择、搜索/筛选、打开账号、查看详情、选择后批量同步/恢复 | 无工作区、无账号、加载、无搜索结果、只读、失败 | 真实目录加载/失败状态、详情与运行状态入口已实现 |
| 创建/编辑账号 | 账号名称与标识、标签、代理、指纹、保存 | 校验失败、权限不足、保存中、服务端冲突 | 待设计 |
| 账号详情 | 运行状态、指纹设置、同步范围、授权、审计 | 未运行、打开中、配置需重载、同步锁定 | 目录资料和真实本机 Tab 状态已实现，指纹/授权/审计沿账号操作入口提供 |
| 同步与冲突 | 解锁同步、选择类别、批量进度、保留云端/合并/覆盖 | 未解锁、断网、局部失败、版本冲突、租约占用 | 冲突、批量逐账号结果和多账号租约状态已实现 |
| 成员与权限 | 邀请、角色、账号授权、移除 | 邀请过期、只读、失权、提交失败 | 成员加载/失败、移动角色说明和账号授权加载反馈已实现 |
| 设备与安全 | 当前会话、撤销设备、退出、受保护会话状态 | 原生不可用、撤权失败、需要重新登录 | 当前设备摘要、保护能力状态和会话加载反馈已实现 |
| 登录/接受邀请 | 登录、有效邀请加入工作区 | 提交中、错误密码、会话过期、邀请无效 | 待设计 |
| 代理与产品设置 | 代理认证引用、产品化配置 | 依赖后续真实接口；接口未接入时不展示可用的假操作 | 待设计与对应接口 |

本轮设计稿位于 `design/saas-workbench-desktop.svg` 与 `design/saas-workbench-mobile.svg`，展示“尚未选择工作区”的真实初始状态，不填入虚构账号、在线数量、任务成功率或收费套餐。设计稿仅用于视觉设计，生产页面继续位于 `saas-web/`，未把静态稿当作可用业务交付。

## 设计规范

- 桌面参考画布 1440×960，固定侧栏约 224 px；主要空间用于环境列表，不在工作台堆放营销区块。
- 移动参考画布 390×844；使用顶部工作区入口与底部导航，表格转为保留主要信息的账号卡片。禁止仅缩小桌面表格。
- 中文正文优先 14 px，辅助信息 12 px；账号标识可用等宽字。标题 20～24 px，避免后台页面使用超大营销标题。
- 基础间距 4 px，表单控件 36～40 px；移动可点击区域至少 44 px。圆角 6～10 px，分隔线单层，阴影只用于浮层。
- 表格包含账号、标签、运行状态、同步状态、负责人/权限及操作；未知状态显示“待读取”或“—”，不能用 0 或“正常”替代。
- 批量工具栏仅在真实选择后出现，展示选中数量；只读用户禁用写入动作，并说明权限原因。批量失败保留逐账号结果。
- 编辑界面优先侧边面板；确认覆盖、撤销设备等动作使用有明确后果的对话框。移动编辑采用全屏面板。
- 同步能力始终可用，用户选择同步的数据类别；不设置关闭全部同步能力的开关。密码使用“环境加密密码”，与登录密码区分。
- 用户文案使用“账号环境”“运行状态”“环境同步”等业务用语；原生桥、StoragePartition、JNI 等细节放诊断页。
- 保留可见焦点、键盘导航、标签与错误关联、屏幕阅读器状态提示；正文对比度以 WCAG AA 为目标，不声称已经通过整体验收。

## 开发任务

1. 已完成：商业参考梳理、任务路径与组件规范、桌面/移动初始空状态首版高保真稿。
2. 生产页面首轮编码已完成：账号列表、设备安全、同步冲突、成员权限、设备会话、账号详情、批量逐账号结果和移动全屏面板均接入真实接口；高保真图仍只表达初始空状态。
3. 进行中：`saas-web/` 已完成首轮浅色 shadcn 主题和安卓底部导航，继续优化信息层级与响应式细节，保留真实接口与现有权限约束。
4. 已完成首轮：真实账号列表接入搜索、权限筛选、选择与批量同步/恢复工具栏；已补充账号目录加载/失败状态、账号详情及真实本机运行状态读取。
5. 已完成本轮：补充批量租约多账号状态、运行 Tab/设备/成员加载语义、移动权限角色说明和进度条无障碍属性；仍需后续做真实多设备与移动设备运行验收。
6. 暂缓：新 Chromium 与 Android 的整体验收、真实多设备联调和发布验收，按用户后续指令安排。

本轮采用 product-designer 的任务路径、状态覆盖和组件规范，以及 frontend-design 的视觉一致性要求；技能包附带参考文件缺失时采用已读取的主规范和上述官方参考。没有虚构用户访谈、可用性评分或商业产品体验测试结果。
